# AID Scene Classification

This project develops and compares four CNN models from scratch for multi-class aerial scene classification using a subset of the AID dataset.

## Dataset

The project uses 10 selected classes from the AID dataset:

- Forest
- Desert
- Beach
- River
- Mountain
- DenseResidential
- Industrial
- Airport
- Stadium
- Farmland

The raw images are not included in this repository because of their large size.
